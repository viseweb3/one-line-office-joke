One original one-line joke about office life, written for make.fun's "One-Line Office Joke Laugh-Off" bounty: **"I asked for a standing desk and got a standing meeting instead — same back pain, now with an audience."**

Why this line: it is genuinely one line and one sentence, it is about office life (the standing desk everyone was promised, the standing meeting nobody asked for), the punchline lands instantly with no explanation, and the twist — same back pain, now with an audience — is a fresh angle on the overused meeting joke rather than another plant, printer, or "we're a family here" gag. Setup, then twist, then stop.

## Run it

```sh
node main.ts
```

It prints exactly one line: the joke.
